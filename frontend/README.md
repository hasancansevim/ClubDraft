# ClubCraft — Frontend

React + TypeScript + Vite ile yazılmış ClubCraft istemcisi (Ana Sayfa →
Lobi → Draft → Sezon Dashboard'u → Sponsorluk → Sezon Sonu).

Projenin genel mimarisi, backend servisleri ve çalıştırma talimatları için
kök dizindeki [`../README.md`](../README.md) ve
[`../docs/ClubCraft-Spec.md`](../docs/ClubCraft-Spec.md) (§6, görsel
tasarım sistemi ve frontend ilerleme günlüğü dahil) dosyalarına bakın.

## Geliştirme

```bash
npm install
npm run dev      # http://localhost:5173, ApiGateway'in ayakta olmasını bekler
npm run build
npm run lint      # oxlint
```
